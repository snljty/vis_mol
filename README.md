# <center> vis_mol </center>
C 语言的简易分子可视化程序。
除了几行着色器代码的 GLSL，整个程序由纯 C 语言构成。

支持 Gaussian 的.gjf、.out、.fch 格式和标准的 .xyz 格式。

编译使用了 FreeGLUT 作为 GLUT 库用来处理窗口、事件响应、OpenGL 上下文、双缓冲交换、事件循环等，默认动态链接，所以运行需要 GNU 编译器编译的 libfreeglut.dll。
FreeGLUT 库可以从 [FreeGLUT](https://freeglut.sourceforge.net/ "FreeGLUT") 下载并自行编译。

编译还使用了 GLAD 库作为适配器从驱动中动态获得 OpenGL 函数地址，取代上一代的 GLEW。 可以从 [GLAD](https://glad.dav1d.de/ "GLAD") 下载。

编译还依赖可选的 UTHash 库 [UTHash](https://troydhanson.github.io/uthash/ "UTHash")，这个库只有头文件，用来提供 Hash 表。
如果有这个库，元素周期表里面元素名字查原子序号和正二十面体细分球（棱角球）的顶点索引去重，理论上可以对顶点个数或者原子个数做到 \(O(N)\) 时间复杂度。如果没找到这个库，顶点索引去重用的排序算法，理论时间复杂度 \(O(N \log N)\)，而对每个原子的原子序号查询则线性遍历元素周期表。

注释尽可能详细描述了所有显式用到的计算机图形学算法和 OpenGL 的一些基本原理和步骤。

tools 里面的工具单纯是为了把 shaders 目录中的着色器源码转成 C 语言头文件格式方便编译和高级文本编辑器的语法高亮。

使用 OpenGL 可编程管线。目前版本默认圆柱就是当成正棱柱细分，球用正二十面体细分球处理，虽然也保留了经纬球的源代码。

交互模式：
分子坐标不变，同时光线随着视角同步变化，确保不同视角只是为了查看分子不同方向，光线效果不变。
采用 Exocentric（物体中心 / 外部参照）交互而非 Egocentric（自我中心 / 相机参照）交互，即用户“抓住”物体移动它。旋转中心固定在分子自身上，避免类似公转的效果。
下面描述屏幕向右定义为 x 轴，向上定义为 y 轴，向外定义为 z 轴。
平移旋转等操作的轴，永远是基于当前视图的，即视图空间旋转（view-space rotation），不管分子之前被转成什么姿态，下一次拖拽产生的旋转轴总是相对于当前屏幕方向来定。
鼠标左键按住，左右移动是让分子离用户较近的部分往左/往右旋转，即绕 y 轴顺时针/逆时针旋转；上下移动是分子离用户较近的部分往上/往下旋转，即绕 x 轴顺时针/逆时针旋转。
鼠标中键按住，左右移动是让分子在 x 方向左右移动；上下移动是让分子在 y 方向上下移动。
鼠标右键按住，左右移动是让分子在 z 方向逆时针/顺时针转动，也就是分子的上半部分往左/右转动；上下移动是沿视线方向把分子推远/拉近（移动的还是相机位置）。
鼠标滚轮向前（向上）/向后（向下）对应的是缩放，分别是让分子显得缩小/放大，如果按照近大远小的感觉，就相当于把分子变远/近。
双击鼠标中键调整回初始视角。注意初始视角自动让分子居中了。
按键盘左右中括号切换近裁平面距离更近/更远，左右大括号切换近裁平面距离更近/更远。
按键盘 v 切换正交/透视视角。
按键盘 Esc 退出。
